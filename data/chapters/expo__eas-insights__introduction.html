Expo Insights is a dashboard that surfaces trends across your project so you can see how your app is doing at a glance. Open your project in the Expo dashboard and select Insights from the navigation menu.

Insights groups data into three tabs:

  • App usage: Usage of your app across platforms, app store versions, and time, aggregated from Expo Update requests and the expo-insights library.
  • Workflows: Run counts, success rates, and trends for your Expo Workflows.
  • Maestro: Pass, flake, and failure trends for the Maestro end-to-end tests you run in Expo Workflows.
