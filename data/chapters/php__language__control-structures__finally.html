Throwable error handling with a block

When the call stack is unwound after a Throwable error has been thrown, all blocks it encounters along the way will be executed. In other words, nested blocks are executed even if the Throwable error is not caught by an adjacent block.

Interaction between a block and a statement

One notable interaction is between the block and a statement. If a statement is encountered inside either the or the block, the block will still be executed. Moreover, the statement is evaluated when encountered, but the result will be returned after the block is executed. Additionally, if the block also contains a statement, the value from the block is returned.
