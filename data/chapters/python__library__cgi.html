This module is no longer part of the Python standard library. It was removed in Python 3.13 after being deprecated in Python 3.11. The removal was decided in [594].

A fork of the module on PyPI can be used instead: [legacy-cgi]. This package contains copies of the [!cgi] and [!cgitb] modules, which are no longer maintained or supported by the core Python team.

The last version of Python that provided the [!cgi] module was Python 3.12.
