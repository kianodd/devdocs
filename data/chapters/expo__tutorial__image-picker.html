React Native provides built-in components as standard building blocks, such as , , and ``. We are building a feature to select an image from the device's media library. This isn't possible with the core components and we'll need a library to add this feature in our app.

We'll use expo-image-picker, a library from the Expo SDK.

expo-image-picker provides access to the system's UI to select images and videos from the device's media library.
