The init keyword defines an accessor method in a property or indexer. An init-only setter assigns a value to the property or the indexer element only during object construction. An init enforces immutability, so that once the object is initialized, it can't be changed. An init accessor enables calling code to use an object initializer to set the initial value. In contrast, an automatically implemented property with only a get accessor must be initialized by calling a constructor. A property with a private set accessor can be modified after construction, but only in the class.
