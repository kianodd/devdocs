You can run MongoDB Community Edition as a Docker container using the official MongoDB Community image. This page describes how to install, run, verify, and connect to MongoDB Community Edition in Docker.

Before You Begin

Before you install MongoDB Community Edition on Docker, complete the following prerequisites:

  • Install Docker on your host.
  • Install mongosh .
  • Confirm that your host platform is supported. To learn which platforms MongoDB runs on, see prod-notes-supported-platforms.

Start and Verify

Run the Image as a Container

Run the following command to start a container named [mongodb] from the image:

`sh docker run --name mongodb -p 27017:27017 -d mongodb/mongodb-community-server:{+version+}-ubi9-slim`

The [-d] flag runs the container in the background. The [-p 27017:27017] flag publishes the container port to the host port.

You can append mongod command-line options

: to the [docker run]

command. For example, to start a single-node replica set instead, run the following command:

`sh docker run --name mongodb -p 27017:27017 -d mongodb/mongodb-community-server:{+version+}-ubi9-slim --replSet myReplicaSet`

Verify That the Container Is Running

To list running containers, run [docker ps]. The output includes the container ID, image, status, and published ports:

Connect

Connect to the MongoDB Deployment

To connect to your deployment, run `mongosh`:

`sh mongosh`

Because the [docker run] command publishes the container port to the host, [mongosh] connects to the default address, [localhost:27017].

Report the MongoDB Server Status

To report the status of your MongoDB instance, run the [serverStatus] command:

`javascript db.runCommand( { serverStatus: 1 } )`

The command returns a document that describes your [mongod] deployment.
