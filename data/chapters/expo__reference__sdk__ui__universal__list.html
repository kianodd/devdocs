List provides a virtualized vertical container of rows, typically populated with ListItem children. It provides the platform-native chrome (separators, inset styling, pull-to-refresh). ListItem is a tappable row with leading/trailing/supportingText slots.

info For large data sets, render rows with List.ForEach. It mounts only the rows near the visible range, and reuses them while the list scrolls.

Native implementations

Platform Backing component
Android Jetpack Compose LazyColumn. When you provide onRefresh, List wraps it in PullToRefreshBox.
iOS SwiftUI List. When you provide onRefresh, List applies the refreshable modifier.
Web React Native View with scrolling overflow.

Installation

Usage

Basic list

Rows with slots

ListItem accepts leading, trailing, and supportingText shorthand props for the common case. Pass a ReactNode for any of them when richer content is needed.

Compound slot children

For full control over slot content, use the compound API: <ListItem.Leading>, <ListItem.Trailing>, and <ListItem.Supporting>. Anything not wrapped in a slot becomes the headline.

Large data sets

List.ForEach renders one row for each item of data. It mounts a small pool of rows around the visible range and reuses them while the list scrolls. Rows that are not ready yet show a placeholder of estimatedItemSize.

Wrap the render function in useCallback. A recycled row keeps its local state (useState) when it shows another item. Keep row state outside the row, or reset it when the item changes. You can put static rows before and after List.ForEach in the same List.

Pull-to-refresh

Pass an async onRefresh handler. The platform-native refresh indicator stays visible until the returned promise settles (resolves or rejects).

Pull-to-refresh is not implemented on web yet. The handler is accepted for API parity but the indicator only appears on Android and iOS.
