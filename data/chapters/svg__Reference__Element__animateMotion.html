The <animateMotion> SVG element provides a way to define how an element moves along a motion path.

[!NOTE] To reuse an existing path, it will be necessary to use an mpath element inside the <animateMotion> element instead of the path attribute.

Usage context

Attributes

  • keyPoints
    • : This attribute indicates, in the range [0,1], how far the object is along the path for each associated value in keyTimes. Value type: <number>*; Default value: none; Animatable: no
  • path
    • : This attribute defines the path of the motion, using the same syntax as the attribute. Value type: <string>; Default value: none; Animatable: no
  • rotate
    • : This attribute defines a rotation applied to the element animated along a path, usually to make it pointing in the direction of the animation. Value type: <number> | auto | auto-reverse; Default value: 0; Animatable: no

[!NOTE] For <animateMotion>, the default value for the calcMode attribute is paced.

Animation Attributes

  • Animation timing attributes
    • : begin, dur, end, min, max, restart, repeatCount, repeatDur, fill
  • Animation value attributes
    • : calcMode, values, keyTimes, keySplines, from, to, by
  • Other Animation attributes
    • : Most notably: attributeName, additive, accumulate
  • Animation event attributes
    • : Most notably: onbegin, onend, onrepeat

DOM Interface

This element implements the SVGAnimateMotionElement interface.
