PyBytesWriter

The :c`PyBytesWriter` API can be used to create a Python [bytes] object.

A bytes writer object.

The API is not thread safe. To share a writer with multiple threads, a critical section or a lock is needed.

The instance must be destroyed by :c`PyBytesWriter_Finish` on success, or :c`PyBytesWriter_Discard` on error.

Create, Finish, Discard

On error, set an exception and return NULL.
