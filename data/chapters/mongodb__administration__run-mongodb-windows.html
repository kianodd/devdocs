MongoDB Enterprise and MongoDB Community are available to run on Windows as a Windows Service managed with the net command, through the [mongod.exe] command-line interface, or manually through the Services console.

Syntax

net Command

`none net <command> MongoDB`

Services Console

Right-click the MongoDB service in the Services console and select the operation you want to perform.

Manual

`none "C:\Program Files\MongoDB\Server\{+version+}\bin\mongod.exe" <opts>`

Compatibility

On self-managed deployments of MongoDB Enterprise and MongoDB Community installed on Windows, you can manage the [~bin.mongod] process as a Windows Service.

For more information on supported platforms, see:

  • Supported Platforms for MongoDB Enterprise
  • Supported Platforms for MongoDB Community

Behavior

User Privileges

Most commands that manage a Windows Service require elevated privileges. Open the Windows command prompt (cmd.exe) as an Administrator before you run these commands.

By default, the service runs in the context of a local system account. To run the service as a specific user, register it with the [--serviceUser ] and [--servicePassword ] options. That user must have the Log on as a service privilege.

Service Registration

The Windows installer registers the MongoDB service for you, and the service starts when the installation succeeds. The service also starts when the system boots.

If you installed MongoDB from the ZIP archive, you must register the service yourself with the [--install ] option before you can manage it with the net command.

Examples

Register the MongoDB Service

To register [mongod.exe] as a Windows Service, run [mongod.exe] with the [--install ] option. Pass the [--config ] option to register the service with the configuration file it reads at startup:

The service stores the options you register it with. When you later start the service with net start MongoDB, it reads the configuration file you specified here.

You need to register the service only once. The Windows installer performs this step for you.

Start MongoDB

To start the MongoDB service, use one of the following methods:

net Command

`none net start MongoDB`

Services Console

Right-click the MongoDB service in the Services console and click Start.

Manual

`none "C:\Program Files\MongoDB\Server\{+version+}\bin\mongod.exe" --dbpath="C:\data\db"`

This command runs [mongod.exe] in the foreground. The [--fork ] option is not supported on Windows.

Verify MongoDB Is Running

sc Command

If you started MongoDB as a Windows Service, query the service from the command prompt:

`none sc query MongoDB`

The command returns the service details. The [STATE] field reads [RUNNING] when the service is running and [STOPPED] when it is not.

Services Console

If you started MongoDB as a Windows Service, locate the MongoDB service in the Services console. You should see the service listed as [Running] in the Status column.

Manual

If you started MongoDB manually in the foreground, the Command Interpreter displays the following line when the database server is running correctly:

`none [initandlisten] waiting for connections`

To show runtime information for the running [mongod.exe] process, use [~bin.mongosh] to run the [serverStatus] command:

You can also view the log file to see the current status of your [mongod.exe] process. The log file is the path you set with the [--logpath ] option.

Stop MongoDB

To stop the MongoDB service, use one of the following methods:

net Command

`none net stop MongoDB`

Services Console

Right-click the MongoDB service in the Services console and click Stop.

Manual

Connect to the server with [~bin.mongosh] and run the [db.shutdownServer()] method on the [admin] database:

`none mongosh admin --quiet --eval "db.shutdownServer()"`

The [--shutdown ] option is available only on Linux systems. If you started [mongod.exe] in the foreground, you can also press [Ctrl] + [C] in the Command Interpreter to shut down the process cleanly.

Restart MongoDB

To restart the MongoDB service, use one of the following methods:

net Command

`none net stop MongoDB net start MongoDB`

Services Console

Right-click the MongoDB service in the Services console and click Restart.

Manual

Connect to the server with [~bin.mongosh] and run the [db.shutdownServer()] method on the [admin] database. Then, use [mongod.exe] to start the server again:

`none mongosh admin --quiet --eval "db.shutdownServer()" "C:\Program Files\MongoDB\Server\{+version+}\bin\mongod.exe" --dbpath="C:\data\db"`
