LocalImageUsedWrongly: Image's and getImage's src parameter must be an imported image or a URL, it cannot be a string filepath. Received IMAGE_FILE_PATH.

What went wrong?

When using the default image services, Image's and getImage's src parameter must be either an imported image or a URL, it cannot be a string of a filepath.

For local images from content collections, you can use the image() schema helper to resolve the images.
