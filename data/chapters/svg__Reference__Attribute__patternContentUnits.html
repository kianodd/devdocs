The patternContentUnits attribute indicates which coordinate system to use for the contents of the pattern element.

[!NOTE] That this attribute has no effect if attribute viewBox is specified on the pattern element.

You can use this attribute with the following SVG elements:

Examples

Elements

You can use this attribute with the SVG elements described in the sections below.

<pattern>

For , patternContentUnits defines the coordinate system in use for the content of the element.

Value userSpaceOnUse | objectBoundingBox
Default value userSpaceOnUse
Animatable Yes
  • userSpaceOnUse
    • : This value indicates that all coordinates inside the element refer to the user coordinate system as defined when the pattern tile was created.
  • objectBoundingBox
    • : This value indicates that all coordinates inside the element are relative to the bounding box of the element the pattern is applied to. A bounding box could be considered the same as if the content of the pattern were bound to a "0 0 1 1" viewBox for a pattern tile of width and height of 100%.
