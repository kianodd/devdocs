Basic config

To enable Content Security Policy (CSP) in your Django project:

  1. Add the CSP middleware to your [MIDDLEWARE] setting:
  1. Configure the CSP policies in your settings.py using either [SECURE_CSP] or [SECURE_CSP_REPORT_ONLY] (or both). The CSP Settings docs provide more details about the differences between these two:

Nonce config

To use nonces in your CSP policy, beside the basic config, you need to:

  1. Include the [~django.utils.csp.CSP.NONCE] placeholder value in the CSP settings. This only applies to script-src or style-src directives:
  1. Add the [~django.template.context_processors.csp] context processor to your [TEMPLATES] setting. This makes the generated nonce value available in the Django templates as the csp_nonce context variable:

  1. In your templates, add the nonce to elements that require it:

    For inline <style> or <script> tags, use the csp_nonce context variable directly:

    For external <script src="..."> and <link rel="stylesheet"> elements, use the [csp_nonce_attr] template tag:

    To render a [~django.forms.Media] object's assets with the nonce applied to each element, pass the object to the [csp_nonce_attr] tag:
