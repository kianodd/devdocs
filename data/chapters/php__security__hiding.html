In general, security by obscurity is one of the weakest forms of security. But in some cases, every little bit of extra security is desirable.

A few simple techniques can help to hide PHP, possibly slowing down an attacker who is attempting to discover weaknesses in your system. By setting expose_php to off in your file, you reduce the amount of information available to them.

Another tactic is to configure web servers such as apache to parse different filetypes through PHP, either with an directive, or in the apache configuration file itself. You can then use misleading file extensions:

Hiding PHP as another language

Or obscure it completely:

Using unknown types for PHP extensions

Or hide it as HTML code, which has a slight performance hit because all HTML will be parsed through the PHP engine:

Using HTML types for PHP extensions

For this to work effectively, you must rename your PHP files with the above extensions. While it is a form of security through obscurity, it's a minor preventative measure with few drawbacks.
