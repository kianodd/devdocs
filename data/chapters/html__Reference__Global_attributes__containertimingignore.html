The containertimingignore global attribute is a boolean attribute that excludes an element and its descendants from contributing to the timing of any ancestor element marked with containertiming. For more details, see the PerformanceContainerTiming interface.

In the DOM, this attribute is reflected as HTMLElement.containerTimingIgnore.
