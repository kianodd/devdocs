Introduction to PIE

is an installer for PHP, that makes it possible to install third-party PHP extensions, that can then be easily installed and updated. It leverages the PHP extension repository part of Packagist to find the source code to build the extension, or a Windows binary to download, if it exists. If it downloads the source code, it also knows how to build and install it.
