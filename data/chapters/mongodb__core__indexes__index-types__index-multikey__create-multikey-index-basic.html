The examples on this page use data from the sample_mflix dataset . For details on how to load this dataset into your self-managed MongoDB deployment, see Load the Sample Dataset . If you made any modifications to the sample databases, you may need to drop and recreate the databases to run the examples on this page.

You regularly run a query that returns movies released before 1910 that have the Short genre. You can create an index on the genres field to improve performance for this query.

Warning

Starting in MongoDB 9.0, if an indexed field becomes a multikey field while a query that references the field is running, the query might fail with a [QueryKilledError]. An indexed field becomes multikey when you insert or update a document so the field contains an array value.

If your query fails with this error, re-run the query after the insert or update operation completes.
