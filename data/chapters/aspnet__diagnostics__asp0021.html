Value
Rule ID ASP0021
Category Usage
Fix is breaking or non-breaking Non-breaking

Cause

An implementation of the BindAsync method has a return type that isn't ValueTask1.

Rule description

This diagnostic is emitted when an implementation of the BindAsync method has a return type that isn't ValueTask.

How to fix violations

To fix a violation of this rule, define a ValueTask return type for BindAsync and consider implementing IBindableFromHttpContext1 to enforce implementation.

When to suppress warnings

Do not suppress a warning from this rule.
