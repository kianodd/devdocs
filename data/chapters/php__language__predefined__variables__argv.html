$argv

Array of arguments passed to script

The first argument $argv[0] is always the name that was used to run the script.

This variable is not available when register_argc_argv is disabled.

To test if a script is being run from the command line, php_sapi_name should be used instead of checking whether $argv or $_SERVER['argv'] is set.
