You can use EAS Command-Line Interface (CLI) to build, update, submit, deploy or use workflows in your Expo and React Native project from a terminal window.

Installation

EAS CLI requires Node.js 20.18.3 or a later Node.js 20 release, or Node.js 22 or later. Use the LTS version of Node.js.

warning Support for Node.js 20 is deprecated. EAS CLI prints a warning when it runs on Node.js 20. A future release will require Node.js 22 or later.
