To set up Expo Build with a monorepo, you need to follow the standard process as described below:

  • Run all EAS CLI commands from the root of the app directory. For example, if your project exists inside your git repository at apps/my-app, then run eas build from there.
  • All files related to Expo Build, such as eas.json and credentials.json, should be in the root of the app directory. If you have multiple apps that use Expo Build in your monorepo, each app directory will have its own copy of these files.
  • If you are building a project that uses Continuous Native Generation (CNG) in a monorepo, see Working with Monorepos guide.
