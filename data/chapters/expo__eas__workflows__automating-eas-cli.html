If you're using EAS CLI to build, submit, and update your app, you can automate sequences of commands with Expo Workflows. Expo Workflows can build, submit, and update your app, while also running other jobs like Maestro tests, unit tests, custom scripts, and more.

Below you'll find how to set up your project to use Expo Workflows, followed by common examples of EAS CLI commands and how you can run them using Expo Workflows.

Configure your project

Expo Workflows optionally supports a GitHub repository that's linked to your Expo Services project to run. This guide assumes a GitHub repository is linked, and shows how to trigger workflows when pushing to specific branches on GitHub. You can link a GitHub repo to your Expo Services project with the following steps:

  • Navigate to your project's GitHub settings.
  • Follow the UI to install the GitHub app.
  • Select the GitHub repository that matches the Expo project and connect it.
