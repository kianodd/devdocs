The mix-blend-mode CSS property sets how an element's content should blend with its backdrop — the content rendered behind the element within the same stacking context.

[!NOTE] This property blends the element with content behind it in the stacking context. To blend an element's own background layers with each other, use background-blend-mode instead.

Syntax

Values

  • &lt;blend-mode&gt;
    • : The blending mode that should be applied.
  • plus-darker
    • : Blending using the plus-darker compositing operator.
  • plus-lighter
    • : Blending using the plus-lighter compositing operator. Useful for cross-fade effects (prevents unwanted blinking when two overlaying elements animate their opacity in opposite directions).
