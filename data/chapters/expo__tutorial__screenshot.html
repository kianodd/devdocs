In this chapter, we'll learn how to take a screenshot using a third-party library and save it on the device's media library. We'll use react-native-view-shot to take a screenshot and expo-media-library to save an image on device's media library. Web browsers don't give apps access to a media library, so on the web, we'll download the screenshot as an image file.

info So far, we have used third-party libraries, such as react-native-gesture-handler, react-native-reanimated. We can find hundreds of other third-party libraries on React Native Directory depending on a use case.

Prompt for permissions

An app that requires sensitive information, such as accessing a device's media library, has to prompt permission to allow or deny access. The usePermissions() hook from expo-media-library returns the permission permissionResponse and the requestPermission() method to ask for access. Our app only saves images to the media library, so we'll pass the writeOnly: true option to ask for write access without read access.

When the app loads for the first time and the permission status is neither granted nor denied, the value of the permissionResponse is null. When asked for permission, a user can either grant the permission or deny it. We can add a condition to check if it is not granted. If it is not granted, trigger the requestPermission() method. After getting the access, the value of permissionResponse.granted changes to true.

Save the screenshot on the web

react-native-view-shot can also capture a screenshot on the web. However, expo-media-library works only on Android and iOS. On the web, we'll download the screenshot as an image file instead.

Using Platform module from React Native, we can implement platform-specific behavior. On the web, captureRef() returns the screenshot as a data URL when we set the result option to 'data-uri'. We can pass this data URL to a link element to download the image.
