Microsoft SQL Server is an enterprise-grade relational database. In this guide, you will learn how to set up a new TypeScript project from scratch, connect it to SQL Server using Prisma ORM, and generate a Prisma Client for type-safe access to your database.

Prerequisites

You also need:

  • A Microsoft SQL Server database
    • Microsoft SQL Server on Linux for Docker
    • Microsoft SQL Server on Windows (local)
  • Database connection details (host, port, username, password, database name)

Here's what each package does:

  • prisma - The Prisma CLI for running commands like prisma init, prisma migrate, and prisma generate
  • @prisma/client - The Prisma Client library for querying your database
  • @prisma/adapter-mssql - The SQL Server driver adapter that connects Prisma Client to your database
  • @types/mssql - TypeScript type definitions for mssql
  • dotenv - Loads environment variables from your .env file

Note

Prisma ORM 7.10 and later name this file prisma7.config.ts so that it does not clash with the Prisma 8 config format, which only accepts prisma.config.ts. The Prisma 7 CLI discovers either name, so a project that already has a prisma.config.ts keeps working.
