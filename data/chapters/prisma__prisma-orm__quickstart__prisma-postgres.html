Prisma Postgres is a managed PostgreSQL database that scales to zero and works with Prisma ORM and Prisma Studio. In this guide, you will learn how to set up a new TypeScript project from scratch, connect it to Prisma Postgres using Prisma ORM, and generate a Prisma Client for type-safe access to your database.

Prerequisites

  • Node.js v20.19 or later
  • No database needed: you create a Prisma Postgres database with one command in step 4

2. Install required dependencies

Here's what each package does:

  • prisma - The Prisma CLI for running commands like prisma init, prisma migrate, and prisma generate
  • @prisma/client - The Prisma Client library for querying your database
  • @prisma/adapter-pg - The node-postgres driver adapter that connects Prisma Client to your database
  • pg - The node-postgres database driver
  • @types/pg - TypeScript type definitions for node-postgres
  • dotenv - Loads environment variables from your .env file

4. Initialize Prisma ORM

You can now run Prisma CLI commands using your package manager:

Next, set up your Prisma ORM project by creating your Prisma Schema file with the following command:

prisma init creates the Prisma scaffolding and a local DATABASE_URL.

This command does a few things:

  • Creates a prisma/ directory with a schema.prisma file containing your database connection and schema models
  • Creates a .env file in the root directory for environment variables
  • Creates a prisma7.config.ts file for Prisma configuration

Note

Prisma ORM 7.10 and later name this file prisma7.config.ts so that it does not clash with the Prisma 8 config format, which only accepts prisma.config.ts. The Prisma 7 CLI discovers either name, so a project that already has a prisma.config.ts keeps working.
