Prisma Client supports full-text search for MySQL and for PostgreSQL with the fullTextSearchPostgres preview feature.

[Need ranked or typo-tolerant search on PostgreSQL?]

The search filter on this page wraps PostgreSQL's built-in tsvector matching. For results ranked the way a search engine ranks them, Prisma ORM 8 adds BM25 full-text search through the ParadeDB extension: relevance scores, fuzzy matching, phrase and proximity queries, all typed in the query builder, with the pg_search extension and the index installed by migrations Prisma manages.

See ParadeDB for setup, the index declaration, and the other search operations.
