$_POST

Form data from HTTP POST requests

:::: {#variable.post.basic .example}

$_POST example

Assuming the user sent a POST request with name=Hannes in the body.

To read POST data sent with other content types (e.g. application/json or application/xml) php://input must be used. Unlike $_POST, which only works with application/x-www-form-urlencoded and multipart/form-data, php://input provides direct access to the raw data from the body of the request.
