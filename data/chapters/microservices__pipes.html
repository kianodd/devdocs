Microservice pipes work the same way as regular pipes. The only difference is that they should throw RpcException instead of HttpException. Unless a custom exception filter handles it, an HttpException thrown during message handling reaches the client as a generic Internal server error message.

Hint

The RpcException class is exposed from the @nestjs/microservices package.
