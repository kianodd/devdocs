Utilities for animating elements with CSS animations.

animate-bounce <br> animation: var(--animate-bounce); /* bounce 1s infinite */<br><br> @keyframes bounce {<br> 0%, 100% {<br> transform: translateY(-25%);<br> animation-timing-function: cubic-bezier(0.8, 0, 1, 1);<br> }<br> 50% {<br> transform: none;<br> animation-timing-function: cubic-bezier(0, 0, 0.2, 1);<br> }<br> }<br>
