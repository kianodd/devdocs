You still have some Astro components repeatedly rendered on every page. It's time to refactor again to create a shared page layout!

Create your first layout component

  1. Create a new file at the location src/layouts/BaseLayout.astro. (You will need to create a new layouts folder first.)

  2. Copy the entire contents of index.astro into your new file, BaseLayout.astro.

  3. Check the browser preview again to notice what did (or, spoiler alert: did not!) change.

  4. Add a <slot /> element to src/layouts/BaseLayout.astro just above the footer component, then check the browser preview of your Home page and notice what really did change this time!

  5. Change the script of your BaseLayout.astro layout component to receive a page title via Astro.props instead of defining it as a constant.
