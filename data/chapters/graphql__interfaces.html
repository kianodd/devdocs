Like many type systems, GraphQL supports interfaces. An interface is an abstract type that defines a set of fields that a type must include to implement the interface (see interfaces in the GraphQL documentation).

Code first

In the code first approach, you define a GraphQL interface by creating an abstract class annotated with the @InterfaceType() decorator, exported from the @nestjs/graphql package.

Warning

TypeScript interfaces cannot be used to define GraphQL interfaces.
