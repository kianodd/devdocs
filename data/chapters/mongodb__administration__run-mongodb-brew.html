MongoDB provides a Homebrew tap that allows you to install MongoDB Enterprise and MongoDB Community through the brew package manager. If you installed MongoDB on your macOS system with these formulae, you can also manage the [~bin.mongod] process as a service through the brew services command.

Syntax

Enterprise

`bash brew services <cmd> mongodb-enterprise[@VERSION]`

Community

`bash brew services <cmd> mongodb-community[@VERSION]`

Commands

stub-columns : 1

widths : 20 80

  • Command
    • Description
  • [info]
    • Shows the status of the MongoDB service.
  • [restart]
    • Stops the MongoDB service if running, starts it again, and then re-registers it to start at login or boot.
  • [run]
    • Starts the MongoDB service. Does not register it to start at login or boot.
  • [start]
    • Starts the MongoDB service and registers it to start at login or boot.
  • [stop]

    • Stops the MongoDB service and removes it from the registry of services to start at login or boot.

      [IMPORTANT:]

      To stop the process but keep it registered to start on login or boot, use the [--keep] option.

Compatibility

On self-managed deployments of MongoDB Enterprise and MongoDB Community installed on macOS through Homebrew, you can manage the [~bin.mongod] process as a Homebrew service through the brew services command.

For details on supported platforms, see:

  • Supported Platforms for MongoDB Enterprise
  • Supported Platforms for MongoDB Community

Homebrew Registry

Some Homebrew services commands, like start, stop, and restart interact with a registry that controls persistent services through launchd.

Versioned Formula Syntax

Homebrew allows you to install multiple versions of a particular package on an individual system. If you start a service without specifying the version, Homebrew starts the latest version available.

Enterprise

`bash brew services <cmd> mongodb-enterprise@{+version+}`

Community

`bash brew services <cmd> mongodb-community@{+version+}`

Use the versioned formula syntax when you register the MongoDB service with launchd. This syntax ensures that Homebrew continues to start the MongoDB service with the specified version until you are ready to transition to the next major or minor release.

Logging

brew services directs the [~bin.mongod] log messages to a log file in the Homebrew prefix. The default log file is $(brew --prefix)/var/log/mongodb/mongo.log.

Stop MongoDB

To stop the MongoDB service and remove it from the startup registry, run the following command:

Enterprise

`bash brew services stop mongodb-enterprise@{+version+}`

Community

`bash brew services stop mongodb-community@{+version+}`

Restart MongoDB

To restart the [~bin.mongod] process, run the following command:

Enterprise

`bash brew services restart mongodb-enterprise@{+version+}`

Community

`bash brew services restart mongodb-community@{+version+}`

This command also re-registers the Homebrew service to start on login.

Start MongoDB on Login

To start the MongoDB service and register it with Homebrew to start on login, run the following command:

Enterprise

`bash brew services start mongodb-enterprise@{+version+}`

Community

`bash brew services start mongodb-community@{+version+}`

To start the MongoDB service at boot, run the preceding command with sudo.

To start MongoDB only for the current session and have it shut down when you log out or reboot, see manual-brew-run.
