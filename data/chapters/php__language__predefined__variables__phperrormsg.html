$php_errormsg

The previous error message

Use error_get_last instead.

If a user defined error handler (set_error_handler) is set $php_errormsg is only set if the error handler returns .

8.0.0 Directive track_errors which caused $php_errormsg to be available has been removed. 7.2.0 Directive track_errors which caused $php_errormsg to be available has been deprecated.
