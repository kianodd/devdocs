Coming from another language? string.Split is C#'s counterpart to Java's String.split and JavaScript's String.prototype.split. Unlike those languages, C# returns an array (string[]), not a list, and the separator argument is a character or string, not a regular expression. For pattern-based splitting, see Split?displayProperty=nameWithType.

The Split?displayProperty=nameWithType method breaks a string into an array of substrings using one or more separators. It's the simplest way to parse delimited text such as words, CSV-style values, or protocol tokens.

The method has many overloads, but they cover four independent decisions:

  • Separators: one char, an array of char, one string, or an array of string.
  • Maximum result count: cap the number of substrings returned.
  • Empty-entry handling: keep empty substrings (the default) or drop them with RemoveEmptyEntries?displayProperty=nameWithType.
  • Whitespace handling: trim leading and trailing whitespace from each entry with TrimEntries?displayProperty=nameWithType.
