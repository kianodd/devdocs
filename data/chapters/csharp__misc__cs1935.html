Could not find an implementation of the query pattern for source type 'type'. 'method' not found. Are you missing a using directive for 'System.Linq'?

The source type in a query must be IEnumerable, IEnumerable, or a derived type, or a type for which you or someone else has implemented the standard query operators. If the source type is an IEnumerable or IEnumerable, you must add a using directive for the System.Linq namespace in order to bring the standard query operator extension methods into scope. Custom implementations of the standard query operators must be brought into scope in the same way, with a using directive and, if necessary, a reference to the assembly.

To correct this error

Add the required using directives and references to the project.
