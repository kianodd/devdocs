Keyword 'this' is not available in the current context

The this keyword was used in a context where it is not valid. Common causes include:

  • The this keyword was found outside of an instance method, instance property, constructor, or indexer (for example, in a field initializer or a static method).
  • The this parameter modifier was used on a method declaration inside an extension declaration block. In an extension declaration, extension members are declared as instance members without the this modifier on their parameters because the receiver is specified in the extension header.
