The padding-left CSS property sets the width of the padding area to the left of an element.

An element's padding area is the space between its content and its border.

[!NOTE] The padding property can be used to set paddings on all four sides of an element with a single declaration.

Syntax

The padding-left property is specified as a single value chosen from the list below. Unlike margins, negative values are not allowed for padding.

Values

  • &lt;length&gt;
    • : The size of the padding as a fixed value. Must be non-negative.
  • &lt;percentage&gt;
    • : The size of the padding as a percentage, relative to the inline size (width in a horizontal language, defined by writing-mode) of the containing block. Must be non-negative.
