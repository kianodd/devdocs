Once you have a migration to run on production, you can run them using a CLI command:

typeorm migration:create and typeorm migration:generate will create .ts files, unless you use the o flag (see more in Generating migrations). The migration:run and migration:revert commands only work on .js files. Thus the typescript files need to be compiled before running the commands. Alternatively, you can use ts-node with typeorm to run .ts migration files.
