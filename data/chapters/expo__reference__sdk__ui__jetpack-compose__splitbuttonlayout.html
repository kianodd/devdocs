Expo UI SplitButtonLayout matches the official Jetpack Compose SplitButtonLayout API. It places a leading button for the primary action next to a trailing button, which usually opens a menu of related actions. Both buttons take the same height.

Installation

Usage

Split button with a menu

SplitButtonLayout has two slots: SplitButtonLayout.LeadingButton and SplitButtonLayout.TrailingButton. Put a SplitButtonLeadingButton in the leading slot. To open a menu from the trailing button, put a DropdownMenu in the trailing slot with a SplitButtonTrailingButton as the menu's trigger. The menu then opens below the button. Set checked on the trailing button while the menu is expanded. Material 3 changes the shape of a checked button to show that the menu is open.

The slots accept other content too. For example, wrap the trailing button in a TooltipBox to show a tooltip on long press.

Full-width split button

The layout measures the trailing button first and gives the leading button the remaining width. Apply fillMaxWidth() to both the layout and the leading button to make the split button span its container.
