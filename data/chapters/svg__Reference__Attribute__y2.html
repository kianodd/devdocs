The y2 attribute is used to specify the second y-coordinate for drawing an SVG element that requires more than one coordinate. Elements that only need one coordinate use the y attribute instead.

Elements

You can use this attribute with the SVG elements described in the sections below.

<line>

For , y2 defines the y coordinate of the ending point of the line.

Value <length> | <percentage> | <number>
Default value 0
Animatable Yes

<linearGradient>

For , y2 defines the y coordinate of the ending point of the gradient vector used to map the gradient stop values. The exact behavior of this attribute is influenced by the attributes

Value <length>
Default value 0%
Animatable Yes
