The <aside> HTML element represents a portion of a document whose content is only indirectly related to the document's main content. Asides are frequently presented as sidebars or call-out boxes.

Attributes

This element only includes the global attributes.

Usage notes

  • Do not use the <aside> element to tag parenthesized text, as this kind of text is considered part of the main flow.
  • The <aside> element has an implicit role of complementary, unless it has no accessible name and is nested in sectioning content, in which case it has the generic role.

Technical summary

Content categories Flow content, sectioning content, palpable content.
Permitted content Flow content.
Tag omission None, both the starting and ending tag are mandatory.
Permitted parents Any element that accepts flow content. Note that an <aside> element must not be a descendant of an `address` element.
Implicit ARIA role complementary, or generic when it has no accessible name and is nested in sectioning content
Permitted ARIA roles feed, none, note, presentation, region, search
DOM interface `HTMLElement`
