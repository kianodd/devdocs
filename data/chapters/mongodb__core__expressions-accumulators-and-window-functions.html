Some aggregation operators, such as $avg, $sum, and $max, appear in more than one context, and each context gives the operator different behavior. For example:

  • As an expression, $avg returns the average of the elements in an array.
  • As an accumulator, $avg returns the average of values across a group of documents.
  • As a window function, $avg returns the average of values from the documents in a window.

The stage that contains an operator determines its behavior. The same operator name can accept different arguments and return different results depending on where you use it. This page describes the three contexts and how to disambiguate them.

    • Where you can use it
  • Expression

  • Accumulator
    • Aggregates over a group of input documents and returns one aggregate value per group.

  • Window function
    • Evaluated over a window of input documents and returns one value per document.

Expressions

An expression resolves to a value for a single input document. Expressions do not mutate their inputs.

Expressions also provide the arguments for accumulators and window functions. For example, in { $sum: "$price" }, the field path "$price" is an expression.

To learn more, see expressions-ref-landing.

Accumulators

An accumulator calculates a single aggregated value, such as a sum, maximum, or minimum, across a variable number of input documents. In practical implementations, accumulators maintain state between the documents that they process while executing a grouping operation.

The number of output documents returned by a [$group] stage is equal to the number of groups. For each of these groups, an accumulator calculates an aggregate value across the group.

You can use accumulators in the aggregation pipeline stages that perform grouping operations:

  • [$bucket]
  • [$bucketAuto]
  • [$group]

To learn more, see accumulators-ref.

Window Functions

A window function returns a value that is based on a window, which is a span of documents defined relative to the current document. You define the window with the partitionBy, sortBy, and window fields of the [$setWindowFields] stage.

For operators that work as both accumulators and window functions, the difference is what the operator aggregates over and how many values it returns:

  • As an accumulator, the operator aggregates over a group of documents and returns a single value for the group.
  • As a window function, the operator aggregates over a window of documents and returns a value for each document.

You can use window functions only in the [$setWindowFields] stage. [$setWindowFields] also supports operators that are specific to windows, such as $rank and $shift.

To learn more, see window-functions-ref.
