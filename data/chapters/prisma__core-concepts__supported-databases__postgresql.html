Prisma Postgres

Managed PostgreSQL 17 from Prisma, with connection pooling built in.

  • Free plan: 2 GB of storage per workspace and 200,000 operations a month, with no credit card
  • Connection pooling is included on every plan, and any Postgres client works
  • Connection URL: postgres://USER:PASSWORD@pooled.db.prisma.io:5432/postgres?sslmode=require
  • Application traffic uses the pooled host pooled.db.prisma.io (PgBouncer in transaction mode). Prisma Migrate, other CLI commands, and workloads that need session state or LISTEN/NOTIFY use the direct host db.prisma.io.
  • Daily backups on the Starter, Pro and Business plans, taken only on days the database has activity; none on Free. No point-in-time recovery yet; it is coming in November 2026.
  • npx create-db creates a temporary database in seconds, without signing up. It is deleted after 24 hours unless you claim it, which needs a Prisma account.

Resources: Prisma Postgres docs • Connection setup • create-db • Connection pooling

Neon

Serverless PostgreSQL with automatic scaling and branching.

  • Free plan: 1 GB of storage per project, 20 GB across all projects
  • Connection URL: postgres://user:pass@host-pooler.region.aws.neon.tech:5432/db
  • Add -pooler to hostname for connection pooling (PgBouncer, 10k connections)
  • Compute scales to zero after 5 minutes inactivity
  • Compute activation from idle generally takes a few hundred milliseconds, and can be longer after more than 7 days idle
  • Database branching for development workflows

Timeout configuration: Configure connection and pool timeouts via your driver adapter (e.g. connectionTimeoutMillis for pg).

Resources: Neon docs • Connection pooling

Supabase

PostgreSQL hosting with built-in auth, storage, and real-time features.

Free plan: 500 MB database size per project. It is a billing quota, and Supabase's fair-use check sums database size across the organization's projects. The Free disk is 2 GB.

Connection types:

  • Direct: db.[project-ref].supabase.co:5432
  • Transaction pooler: Port 6543 with ?pgbouncer=true
  • Session pooler: Port 5432 on pooler host

Key features:

  • Supavisor connection pooling
  • Built-in PostgreSQL extensions
  • Integrated with Supabase ecosystem
  • Automated backups

Resources: Supabase docs • Prisma integration

Self-hosted PostgreSQL

Standard PostgreSQL server (9.6+).

  • Connection URL: postgresql://user:pass@host:5432/database
  • Full Prisma Migrate support
  • Use prisma migrate dev for development
  • TLS/SSL configuration via connection string parameters

Connection string arguments: Common patterns below covers TLS (sslmode, sslcert), socket connections, setting the schema on the driver adapter, and the Prisma ORM 7 pool defaults. For every pool and timeout setting per driver adapter, see Connection pool.

CockroachDB

Distributed, PostgreSQL-compatible database designed for scalability and high availability.

  • Use provider = "cockroachdb" in schema
  • Connection URL: postgresql://user:pass@host:26257/database
  • Built-in replication and automated failover
  • Horizontal scaling with no single point of failure

Key differences:

Feature PostgreSQL CockroachDB
Native types VARCHAR(n) STRING(n)
ID generation autoincrement() Uses unique_rowid()
Sequential IDs Recommended Avoid (use autoincrement() instead)
