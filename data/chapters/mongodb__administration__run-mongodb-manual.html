To start the MongoDB service manually, run the [~bin.mongod] process directly from the command line with the options and configuration you need.

Compatibility

On self-managed deployments of MongoDB Enterprise and MongoDB Community installed on Linux-based or macOS operating systems, you can manually manage the MongoDB process through [~bin.mongod], and other commands.

Note

Running MongoDB on Windows

On Windows, you manage MongoDB as a Windows Service rather than by running [~bin.mongod] directly. Windows does not support the [--fork ] option. Register the service with [mongod.exe] rather than starting the process from the command line. To learn more, see manual-run-mongodb-windows.

Behavior

User Privileges

When you manually start the MongoDB process, it executes as the user that runs the [~bin.mongod] command.

This user must have read and write access to the [data ] and the [log ] directories. If MongoDB runs as a user who does not have these privileges, it exits with an error.

Examples

Start MongoDB

To start the [~bin.mongod] process, run the following command:

Configuration

`bash mongod --config /path/to/mongod.conf`

Options

`bash mongod --dbpath /path/to/dataDir --logpath /path/to/logs`

On Linux-based operating systems, you can use the [--fork ] option to start MongoDB as a background process.

Stop MongoDB

To stop the MongoDB process, run [~bin.mongod] with the [--shutdown ] option, or connect to the server with [~bin.mongosh] and run the [db.shutdownServer()] method.

Configuration

If you started [~bin.mongod] with a configuration file, you also need to use the [--config ] option when shutting it down. This method only works on Linux-based operating systems.

`bash mongod --config /path/to/mongod.conf --shutdown`

Options

If you started [~bin.mongod] with the [--dbpath ] option, you also need to use this option when shutting it down. This method only works on Linux-based operating systems.

`bash mongod --dbpath /path/to/dataDir --shutdown`

mongosh

To stop the MongoDB process from [~bin.mongosh], run the [db.shutdownServer()] method on the [admin] database:

`bash mongosh admin --quiet --eval "db.shutdownServer()"`

On deployments with [~security.authorization] enabled, you can run [db.shutdownServer()] only when authenticated to the [admin] database. On deployments without authentication enabled, you can also run it through the localhost interface.
