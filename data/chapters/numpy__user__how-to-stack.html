Use [numpy.concatenate], [numpy.stack], or [numpy.block] when you need to join arrays. Choose the function based on whether you want to extend an existing axis, add a new axis, or assemble a nested layout.

Choose a function

Follow this decision guide:

  • [numpy.concatenate] joins arrays along an existing axis. The inputs must have the same shape along all other axes.
  • [numpy.stack] joins equally shaped arrays along a new axis.
  • [numpy.block] assembles arrays using nested lists that describe their arrangement. It concatenates from the innermost lists outward.

Avoid common shape errors

Inspect array.shape before combining arrays to check whether the operation will preserve, add, or extend an axis. In addition to the shape requirements described above, [numpy.block] has two rules of its own:

  • It can prepend leading dimensions of length one to inputs, but it does not broadcast arrays to make incompatible blocks fit.
