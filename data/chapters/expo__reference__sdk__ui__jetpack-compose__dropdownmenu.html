Expo UI DropdownMenu matches the official Jetpack Compose Menu API and displays a dropdown menu when a trigger element is pressed.

Installation

Usage

Basic dropdown menu

React Native components as trigger

You can use a React Native view (such as Pressable) as the dropdown's trigger by wrapping it in RNHostView.

Long-press trigger

Jetpack Compose has no dedicated long-press menu primitive — you compose one from a combinedClickable modifier on the trigger view plus the existing controlled DropdownMenu. The menu anchors to the trigger automatically.

Rounded corners

Use cornerRadius to override the default Material3 menu shape with a custom corner radius (in dp).

Shadow elevation

Use shadowElevation to set the popup shadow elevation in dp. Set it to 0 to remove the shadow, or omit it to use Material 3's default. Modifiers on DropdownMenu apply to the trigger container, so shadow modifiers do not change the popup shadow.

Grouped menu

Use DropdownMenuPopup to show a Material 3 Expressive menu. It matches Compose's DropdownMenuPopup, which has no container of its own. The menu anchors to its parent, so put it in a Box next to the component that opens it. Put the items in DropdownMenuGroup components, with a 2 dp Spacer between the groups. The 2 dp height matches MenuDefaults.GroupSpacing in Compose.

Selectable menu items

Use SelectableDropdownMenuItem for a choice of one option, such as a sort order. It matches Compose's SelectableDropdownMenuItem. A selected item gets a highlighted container and shows its SelectedLeadingIcon in place of its LeadingIcon.

Group and item shapes

By default, each DropdownMenuGroup and SelectableDropdownMenuItem has the shape of a single element. To join them into one stack, set the position of each element as { index, count }:

  • shapes on DropdownMenuGroup: the position of the group in the menu.
  • shape on DropdownMenuItem, or shapes on SelectableDropdownMenuItem: the position of the item in its group.

The first element gets rounder top corners, and the last element gets rounder bottom corners. A DropdownMenuItem without shape is the original Material 3 menu item.
