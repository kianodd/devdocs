MongoDB provides two approaches to In-Use Encryption:

  • {+qe+}
  • {+csfle+} .

Choosing an In-Use Encryption Approach

You can use both {+qe+} and {+csfle+} in the same deployment, but they are incompatible with each other in the same collection. For a comparison of the two, including compatibility with MongoDB versions and points to consider when choosing one or the other, see Choosing an In-Use Encryption Approach .

Encryption Keys and Key Vaults

Both {+qe+} and {+csfle+} use an envelope encryption approach to encrypt data, where an encrypted field in a document uses a unique Data Encryption Key, and those keys are encrypted using a Customer Master Key.

For details, see <qe-reference-keys-key-vaults>.
