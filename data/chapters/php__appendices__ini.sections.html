This list includes the sections you can set to configure your PHP setup on a per Host or Path basis. These sections are optional.

These sections don't directly affect PHP. They are used to group other directives together and to get them to act upon a particular host or on a particular path.

These sections are used only in CGI/FastCGI mode and they can not set extension and zend_extension directives.

Directives set in these sections cannot be overridden by .user.ini files or at runtime, like those set with php_admin_value.

Regardless of their order in , [PATH=] takes precedence over [HOST=], and a deeper path over a shallower one. With PHP-FPM, these sections also take precedence over the pool configuration and FastCGI parameters, including php_admin_value and PHP_ADMIN_VALUE.

[HOST=] INI_SYSTEM
[PATH=] INI_SYSTEM

: Sections

[HOST=<host>]

: This section allows you to define a set of directives that will take effect on the named host.

:::: example
::: title
Activate full on-screen error reporting for dev. domain
:::

::::

[PATH=<path>]

: This section allows you to define a set of directives that will take effect when a script runs from the named path.

:::: example
::: title
Add security script for protected areas
:::
