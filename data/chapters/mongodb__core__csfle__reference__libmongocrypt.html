Overview

Learn how to install libmongocrypt, a core component of {+csfle+}.

The [libmongocrypt] library performs encryption and decryption, and manages communication between the driver and the {+kms-long+} ({+kms-abbr+}).

:::warning Do not build [libmongocrypt] from source. Install and verify the package by following the steps on this page. ::
