Expression or declaration statement expected.

This error occurs when an incorrect control statement is entered when operating in an interactive environment.

The evaluator running in interactive environment (like the Immediate Window of Visual Studio IDE) expects only:

  • a single expression (like a value calculation, or method call),
  • a variable declaration.
