Generator objects are what Python uses to implement generator iterators. They are normally created by calling a generator function, rather than explicitly calling :c`PyGen_New` or :c`PyGen_NewWithQualName`.

The C structure used for generator objects.

The type object corresponding to generator objects.

Return true if ob is a generator object; ob must not be NULL. This function always succeeds.

Return true if ob's type is :c`PyGen_Type`; ob must not be NULL. This function always succeeds.
