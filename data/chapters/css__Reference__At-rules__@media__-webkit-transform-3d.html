The -webkit-transform-3d Boolean CSS media feature is a WebKit extension whose value is true if vendor-prefixed CSS 3D transforms are supported.

[!NOTE] While this media feature is currently supported by most browsers. If possible, use an @supports feature query instead.

Syntax

-webkit-transform-3d is a Boolean CSS media feature whose value is true if the browser supports -webkit prefixed CSS 3D transforms.

Values

  • true
    • : The browser supports the 3D CSS transforms with the -webkit prefix and supports non-standard, prefixed media queries.
  • false
    • : The 3D CSS transforms prefixed with -webkit are not supported by the browser.
