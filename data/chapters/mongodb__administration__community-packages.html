MongoDB provides repositories to install MongoDB Community on Linux-based operating systems through the native package manager.

To install MongoDB Community, see Install .

Considerations

Distribution Packages

The mongodb package provided by most Linux distributions is not maintained by MongoDB, Inc., and conflicts with the official MongoDB Community packages.

If you installed MongoDB through your distribution repositories, uninstall this package before installing from the official MongoDB repositories.
