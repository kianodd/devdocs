The version attribute is used to indicate what specification an SVG document conforms to. It is only allowed on the root svg element. It is purely advisory and has no influence on rendering or processing.

While it is specified to accept any number, the only two valid choices are currently 1.0 and 1.1.

You can use this attribute with the following SVG elements:

  • svg
