Lastly, you can pass an options object (the same BuildSchemaOptions accepted by the buildSchemaOptions property of the GraphQLModule configuration):

  • skipCheck: skip schema validation; boolean, defaults to false
  • orphanedTypes: an array of classes to generate even though they aren't explicitly referenced (i.e., aren't part of the object graph). Normally, a class that is declared but not referenced anywhere in the graph is omitted.

Federation

GraphQLSchemaFactory builds a plain GraphQL schema: it knows nothing about Apollo Federation. To get the SDL of a code first federated subgraph (for example, to pass it to rover subgraph check or rover supergraph compose), print it with printSubgraphSchema from @apollo/subgraph instead of printSchema, so that directives such as @key, @shareable or @external are kept:

Hint

Entity types that are only referenced through _entities (for example, @extends stubs resolved with @ResolveReference()) aren't reachable from the root types, so pass them in orphanedTypes. Otherwise, the schema is generated without them.
