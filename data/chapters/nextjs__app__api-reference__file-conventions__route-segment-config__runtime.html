The runtime option allows you to select the JavaScript runtime used for rendering your route.

  • 'nodejs' (default)
  • 'edge' (deprecated)

Good to know:

  • The Edge Runtime is deprecated. Remove the runtime export from your route files. See Edge Runtime Deprecated.
  • When Cache Components is enabled, remove the runtime export, including runtime = 'nodejs'. Cache Components uses the default Node.js runtime and does not support the runtime route segment config. See Migrating to Cache Components.
  • This option cannot be used in Proxy.
