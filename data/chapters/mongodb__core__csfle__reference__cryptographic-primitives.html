MongoDB encrypts all fields in {+qe+} and {+csfle-abbrev+} with the AEAD AES-256-CBC encryption algorithm.

  • With {+qe+}, ciphertext is always non-deterministic.
  • With {+csfle-abbrev+}, if you specify deterministic encryption for a field, your application passes a deterministic initialization vector to AEAD.
  • With {+csfle-abbrev+}, if you specify random encryption for a field, your application passes a random initialization vector to AEAD.

Note

Authenticated Encryption

MongoDB uses the encrypt-then-MAC approach to perform authenticated encryption. Both {+qe+} and {+csfle-abbrev+} use the HMAC-SHA-256 algorithm to generate your MAC.
