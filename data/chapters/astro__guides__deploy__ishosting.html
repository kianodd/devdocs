is*hosting is a hosting provider offering VPS and dedicated servers in 40+ locations that you can use to self-host a static or server-rendered (SSR) Astro site. A VPS is suitable when your Astro site uses SSR and requires a persistent server, database connections, background jobs, cron jobs, or API routes.

Prerequisites

To deploy your Astro site to an is*hosting VPS, you will need:

  • An Astro project
  • An is*hosting VPS running Ubuntu with SSH access and root or sudo privileges
  • A domain name pointing to your VPS
  • A Node.js version that meets Astro's minimum requirements installed on your VPS

Project configuration

Your Astro project can be deployed to an is*hosting VPS as a static site or as an on-demand rendered site.

Static site

Your Astro project is a static site by default. You don't need any extra Astro configuration to deploy a static site to an is*hosting VPS.

Adapter for on-demand rendering

To enable on-demand rendering in your Astro project, add the Node.js adapter with the following astro add command. This will install the adapter and configure it in standalone mode in your astro.config.mjs file in one step.
