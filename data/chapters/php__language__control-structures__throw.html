The keyword is an expression and may be used in any expression context. It takes a Throwable object as an argument.

Prior to PHP 8.0.0, the keyword was a statement and not an expression.

Attempting to a non-Throwable object will throw an Error. As user classes cannot implement Throwable directly, the thrown object must be an instance of Error or Exception, or of a subclass of one of them.

Throwing a non-Throwable object

After using , the normal flow of execution is halted and the call stack is unwound until the object is caught by a block or the global scope is reached. All blocks encountered along the way are executed. If the global scope is reached, the object is passed to the exception handler set with set_exception_handler, if one is set, and the script terminates once the handler returns. Otherwise, the program is terminated with a fatal error containing the stack trace indicating where the Throwable object was thrown.
