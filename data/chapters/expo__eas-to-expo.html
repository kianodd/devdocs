Expo's cloud services were called EAS (Expo Application Services). Their current name is Expo Services, and each service has an Expo name. The services are the same. Only the names changed. Use this page when you see "EAS" in older documentation, tutorials, or AI answers.

Older name Current name What it does Documentation
EAS, Expo Application Services Expo Services Cloud services for Expo and React Native apps Expo Services
EAS Build Expo Build Builds Android and iOS app binaries in the cloud Expo Build
EAS Submit Expo Submit Submits app binaries to the Google Play Store and the App Store Submit to app stores
EAS Update Expo Update Serves over-the-air updates to apps that use expo-updates Expo Update
EAS Workflows Expo Workflows Runs CI/CD workflows for builds, updates, submissions, and tests Expo Workflows
EAS Hosting Expo Hosting Deploys web projects built with Expo Router Expo Hosting
EAS Metadata Expo Metadata Manages your app store listings from the command line Expo Metadata
EAS Insights Expo Insights Shows trends in app usage, workflow runs, and Maestro tests Expo Insights
EAS Observe Expo Observe Tracks how your app performs in production Expo Observe
EAS Simulator Expo Simulators Runs remote Android Emulators and iOS Simulators Expo Simulators
EAS dashboard Expo dashboard Shows your projects and services on expo.dev expo.dev
EAS CLI EAS CLI Runs Expo Services from your terminal. Its name does not change. EAS CLI

Names that do not change

Code and configuration keep the eas name:

  • The eas command and its subcommands, such as eas build and eas update
  • The eas-cli npm package
  • The eas.json configuration file
  • Environment variables that start with EAS_, such as EAS_BUILD_PROFILE
