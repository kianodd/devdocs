Installation

By default, the oracledb uses the "thin mode" to connect. To enable the "thick mode", you need to follow the installation instructions from their user guide.

Data Source Options

See Data Source Options for the common data source options.

  • sid - The System Identifier (SID) identifies a specific database instance. For example, "sales".
  • serviceName - The Service Name is an identifier of a database service. For example, sales.us.example.com.
