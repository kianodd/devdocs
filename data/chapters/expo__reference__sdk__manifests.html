expo-manifests provides TypeScript types for Expo manifests. A manifest is a JSON object that describes an update. An update is a version of your app's JavaScript bundle and assets.

The library has types for two kinds of manifests:

  • ExpoUpdatesManifest describes an update that your app loads from an update server. This kind of manifest follows the Expo Updates protocol. It includes the update ID, the runtime version, the assets, and your app config in extra.expoClient.
  • EmbeddedManifest describes the update that the build embeds in your app binary.

expo-updates and expo-constants use these types. For example, Updates.manifest contains the manifest of the update that is running. Use these types when your code reads the fields of a manifest. To read your app config, use Constants.expoConfig instead.
