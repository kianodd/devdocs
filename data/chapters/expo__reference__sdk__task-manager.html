expo-task-manager provides an API that allows you to manage long-running tasks, in particular those tasks that can run while your app is in the background. Some features of this library are used by other libraries under the hood. Here is a list of Expo SDK libraries that use TaskManager.

Libraries using Expo TaskManager

  • Location
  • BackgroundTask
  • BackgroundFetch
  • Notifications

Installation


info You can test TaskManager in the Expo Go app. However, check the documentation of each library that uses TaskManager to confirm whether it supports testing in Expo Go.

Configuration 

Standalone apps need some extra configuration: on iOS, each background feature requires a special key in UIBackgroundModes array in your Info.plist file.

Read more about how to configure this in the reference for each of the libraries that use TaskManager.

Usage

info Note: TaskManager.defineTask must be called at module scope, not inside a React component. The example above places it at module scope inside the screen file, which works for non-router apps. In Expo Router projects, move it to a separate file (for example tasks.ts) and import that file at the top of your root layout (app/_layout.tsx) so the task is registered before any navigation runs.
