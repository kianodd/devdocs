A modal presents content above the rest of the app. In general, modals are used to draw a user's attention toward critical information or guide them to take action. A bottom sheet is a type of modal that slides up from the bottom of the screen.

In this chapter, we'll create an emoji picker with the BottomSheet component from Expo UI. On Android and iOS, it displays the platform's native bottom sheet. On web, it displays a sheet at the bottom of the page.

The bottom sheet allows the user to choose an emoji from a list of available emoji. Create an emoji-picker.tsx file inside the src/components directory. This component accepts three props:

  • isVisible: a boolean to determine whether the bottom sheet is visible.
  • onClose: a function to close the bottom sheet.
  • children: used later to display a list of emoji.

Let's learn what the above code does:

  • The BottomSheet component comes from @expo/ui, which the default template already includes. On Android, it displays a Material 3 bottom sheet. On iOS, it displays a SwiftUI sheet. On web, it displays a sheet at the bottom of the page.
  • Its isPresented prop takes the value of isVisible and controls whether the bottom sheet is open or closed.
  • Its onDismiss prop calls onClose when the user closes the bottom sheet. The user can swipe the bottom sheet down or tap outside it. On Android, the back button also closes it. On web, the Esc key also closes it.
  • Its snapPoints prop sets the heights where the bottom sheet can rest. The 'half' value opens it at about half of the screen height.
  • Its containerColor prop sets the background color of the bottom sheet to match the app's background.
  • The RNHostView component displays React Native views, such as and, inside the bottom sheet.
