The patternTransform attribute defines a list of transform definitions that are applied to a pattern tile.

You can use this attribute with the following SVG elements:

Examples

Elements

You can use this attribute with the SVG elements described in the sections below.

<pattern>

For , patternTransform defines a list of transform definitions that are applied to a pattern tile.

[!NOTE] As of SVG2, it is also allowed to use the CSS property. However, the current state of implementation isn't very good. For backward compatibility reason, it is highly suggested to keep using the patternTransform attribute.

Value <transform-list>
Default value Identity transform
