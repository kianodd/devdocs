Prisma 7 remains fully supported; Prisma 8 is a release candidate of Prisma ORM. Scaffold a new Prisma 7 app with npx create-prisma@stable, or add it to an existing project with npx prisma@prev init. This page collects the Prisma 7 starting points: start a new project, add Prisma to an existing one, then deploy.

Note

For a new project, Prisma 8 is the recommended path. It is the next major version of Prisma ORM, now a release candidate. To start with Prisma 8, see the getting started page.

Deploy to Prisma Compute

Once your app runs locally, Prisma Compute runs it next to your Prisma Postgres database:

  1. Port the app to Prisma Composer: add a small TypeScript declaration around your server code, read the port from service.port(), and bind credentials like DATABASE_URL with envSecret in the service's input schema. Port an existing app covers the changes with complete declarations.
  2. Sign in with npx prisma@latest auth login.
  3. Build your server bundle, then run npx prisma@latest deploy with DATABASE_URL exported; the first deploy copies input values from your shell up to the deployment. See Deploying.
  4. Keep deploying from the CLI, or connect GitHub to deploy on push.

For a worked example, from scratch or from an app you already have, follow Deploy your first app.
