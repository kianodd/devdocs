Other related special value functions:

  • [~numpy.isnan] - True if value is nan
  • [~numpy.isinf] - True if value is inf
  • [~numpy.isfinite] - True if not nan or inf
  • [~numpy.nan_to_num] - Map nan to 0, inf to max float, -inf to min float

The following corresponds to the usual functions except that nans are excluded from the results:

  • [~numpy.nansum]
  • [~numpy.nanmax]
  • [~numpy.nanmin]
  • [~numpy.nanargmax]
  • [~numpy.nanargmin]

>>> x = np.arange(10.) >>> x[3] = np.nan >>> x.sum() nan >>> np.nansum(x) 42.0
