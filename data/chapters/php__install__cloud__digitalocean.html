DigitalOcean offers the following platforms to get PHP installed, and running web application on its cloud-hosting infrastructure.

  • Cloudways: One-click deployment of major PHP applications: WordPress, Magento, Drupal, Laravel, and more.
  • Droplet: Virtual machine boxes and installing Lamp stack on a Linux server .
  • App Platform: Managed infrastructure to build, deploy, and scale apps quickly. Learn how to run PHP application on the App Platform .
  • Functions: Serverless platform that allows developers to run code without provisioning or managing servers. PHP is supported natively. Learn how to create serverless functions in PHP .
