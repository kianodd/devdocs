About React Native and Expo tutorial

The objective of this tutorial is to get started with Expo and become familiar with the Expo SDK. It'll cover the following topics:

  • Create an app using the default template with TypeScript enabled
  • Implement a two-screen layout with native tabs from Expo Router
  • Break down the app layout and implement it with flexbox
  • Build native buttons with Expo UI, and use platform-specific files for Android, iOS, and web
  • Use each platform's system UI to select an image from the media library
  • Create an emoji picker with the bottom sheet from Expo UI and the `` component from React Native
  • Add touch gestures to interact with a sticker
  • Use third-party libraries to capture a screenshot, save it to the media library on Android and iOS, and download it on the web
  • Finally, go through the process of configuring a status bar, a splash screen, and an icon to complete the app

These topics provide a foundation to learn the fundamentals of building an Expo app. The tutorial is self-paced and can take up to two hours to complete.

The app uses native UI from each platform. Expo UI brings Jetpack Compose and SwiftUI components to React Native, and it works in Expo Go. On Android, the tab bar, the buttons, and the bottom sheet use Material 3. On iOS 26 and later, the tab bar uses Liquid Glass. On web, the app uses React Native components.

To keep it beginner friendly, we divided the tutorial into eight chapters so that you can follow along or put it down and come back to it later. Each chapter contains the necessary code snippets to complete the steps, so you can follow along by creating an app from scratch or copy and paste it.
