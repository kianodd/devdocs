The reset-project script resets the src/app directory structure in a project. It moves the previous boilerplate files from the project's src and scripts directories to another sub-directory called example. We can delete example since it is not part of our main app's structure. The script file also moves to example, so running reset-project again does not work.

Edit the index screen

The src/app/index.tsx file defines the text displayed on the app's screen. It is the first screen that our app shows. It uses core React Native components such as and to display background and text.

Styles applied to these components use JavaScript objects rather than CSS, which is used on web. However, a lot of the properties will look familiar if you've previously used CSS on web. Most React Native components accept a style prop that accepts a JavaScript object as its value. For more details, see Styling in React Native.

Let's modify src/app/index.tsx screen:

  1. Add a backgroundColor property with the value of #25292e to styles.container. This changes the background color.
  2. Replace the default value of `` with "Home screen".
  3. Add a styles.text object with a color property of #fff (white). Pass it to the style prop of `` to change the text color.

React Native uses the same color format as the web. It supports hex triplets (this is what #fff is), rgba, hsl, and named colors, such as red, green, blue, peru, and papayawhip. For more information, see Colors in React Native.

The gear icon is the Tools button for Android and iOS platforms. It's a floating shortcut that opens the Developer menu, which provides access to debugging functions such as reloading the app and toggling Fast Refresh. It appears only while developing and is never included in a production build.

The remaining screenshots in this tutorial will have it hidden. To hide it:

  1. Open the Developer menu. Shake your device, or press M in the terminal running the development server if you're using an emulator, a simulator, or a device connected with USB.
  2. Find the Tools button option and toggle it off.

Hiding it doesn't disable the Developer menu. You can still open it the way described in Step 1 whenever you need it.
