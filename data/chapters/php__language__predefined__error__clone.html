Clone the error

void

Error::__clone

Errors do not support cloning; this method exists only to prevent it.

Errors cannot be cloned, whether they are instances of Error or of a subclass. Attempting to clone an error throws an Error, which may be caught.

Attempting to clone an error throws an Error with the following message: Trying to clone an uncloneable object of class ClassName.

8.1.0 Error::__clone is no longer final.
