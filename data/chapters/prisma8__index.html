Prisma ORM is the library your TypeScript app uses to read and write its database. You describe your data in a contract, which is the file that holds your models, and Prisma ORM gives you typed queries and migrations for it. If you know Prisma ORM 7, the contract takes the place of schema.prisma, and the queries have a new shape, which the example below shows.

Prisma ORM 8 is a release candidate, not yet a final release, and it is what npm install prisma gives you today. It supports PostgreSQL. MongoDB is in early access, so some of what works on PostgreSQL is missing on it. SQLite ships as an experimental package, @prisma/orm-sqlite. MySQL, SQL Server, and CockroachDB come later, and until then Prisma ORM 7 supports them. Supported databases says what early access and experimental mean, and what works on each database.

Here is a contract with two models, a query that reads them, and what the query prints against a database that holds two users and two posts. The first line of the contract, // use prisma-8, is required, and the setup commands write it for you. db is exported from src/prisma/db.ts, which reads DATABASE_URL and creates the client. For a new app, npm create prisma@latest writes both files. For an app you already have, npx prisma@latest orm init writes them. Run the query file with npx tsx index.ts, after a page under "Start here" has created the tables.

Every field in the result is typed from the contract, down to each post's title. db.orm holds the typed queries for your models, and public is the PostgreSQL schema the table is in, which is the default one unless you created another. After you change the contract, run npx prisma contract emit. It replaces prisma generate, and there is no @prisma/client package: your code imports db from src/prisma/db.ts.

Pick the page that matches where you are starting from. Each page uses PostgreSQL and links its MongoDB version.

  • I — Create an app from a template and run your first query.

  • I have an app, but no database yet — Add Prisma ORM to your app, create the tables, and apply your first migration.

  • I have a database already — Write the contract from the tables you have, then make your first change to the tables as a migration.

  • I have a Prisma 7 app — Install Prisma ORM 8 next to Prisma ORM 7 in the same app, against the same database, and move one part of the app at a time.

Need a database? npx create-db creates a temporary Prisma Postgres database in seconds, without signing up. To host the app, you can deploy it on Prisma Compute.

A create-db database is deleted after 24 hours unless you claim it, which needs a Prisma account. The Prisma CLI deploys apps to Prisma Compute with Prisma Composer. Prisma Compute does not currently support WebSocket servers and has no multi-region deployments (limitations). Prisma Postgres has no point-in-time recovery yet; it is coming in November 2026 (backups).

What you can do with Prisma ORM

  • Model your data: describe your models, their fields, and how they relate to each other.
  • Read and write data: fetch, filter, sort, and paginate records, then create, update, and delete them.
  • Query relations: read related records in the same query with .include(...).
  • Run transactions: make several writes succeed or fail together.
  • Migrate your database: after you change the contract and run npx prisma contract emit, npx prisma migration plan writes the migration for you to review. npx prisma db migrate --advance-ref db then applies it to your development database and records that it did, so the next plan starts from there. The two commands take the place of prisma migrate dev.
  • Add middleware: run your own code before and after every query, for example to log each query. It takes the place of both $use and $extends.
  • Use extensions: add PostgreSQL features such as vector search, geospatial data, and full-text search. These are database extensions, not the $extends of Prisma ORM 7.
  • Use the CLI: run the npx prisma commands for your contract, your database, and your migrations.

Release status

npm install prisma gives you Prisma ORM 8 today. If your app is on Prisma ORM 7 and you want to stay there, lock prisma and @prisma/client to version 7 in package.json, as Release status shows. That page also has the date of the final release and how long Prisma ORM 7 stays supported after it.
