The :-moz-drag-over CSS pseudo-class is a Mozilla extension that matches an element when a dragover event is called on it.

JavaScript

Most elements are not valid places to drop data, so in order to allow a drop, you must prevent default behavior by canceling dragenter or dragover (or both) events. In this example, we only need to cancel the dragenter event, which is the first event fired when the browser evaluates if an element can be a drop target. For more information, see Drag operations: Specifying drop targets.
