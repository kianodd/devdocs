This module is no longer part of the Python standard library. It was removed in Python 3.13 after being deprecated in Python 3.11. The removal was decided in [594].

Encoding and decoding in the uu format can instead be achieved using [codecs.encode] and [codecs.decode], specifying "uu" as the encoding.

The last version of Python that provided the [!uu] module was Python 3.12.
