Turtle star

Turtle can draw intricate shapes using programs that repeat simple moves.

![](turtle-star.png)

Imagine a robotic turtle starting at (0, 0) in the x-y plane. After an import turtle, give it the command turtle.forward(15), and it moves (on-screen!) 15 pixels in the direction it is facing, drawing a line as it moves. Give it the command turtle.right(25), and it rotates in-place 25 degrees clockwise.

Turtle graphics is an implementation of the drawing tools introduced in Logo in 1967. It was created as an educational tool, and its instant, visible feedback makes it an effective way for learners to encounter programming concepts. It is also a convenient way to produce simple graphical output without bringing in external libraries.

This document includes four main sections:

  • turtle-tutorial teaches the basics of turtle drawing.
  • turtle-reference describes the functions, methods and classes this module defines.
  • turtle-howtos detail how to handle specific tasks.
  • turtle-explanation provides background on the object-oriented interface.

Note

Turtle graphics requires the [tkinter] optional module. The python.org installers for Windows and macOS include it, but some Linux distributions and other platforms may package it separately. If import turtle fails with an error mentioning _tkinter, look for documentation from your distributor (that is, whoever provided Python to you). Check this in advance if you're planning to use turtle graphics with a learner.

Reference[]

Turtle methods and functions[]

Most of the examples in this section refer to a Turtle instance called turtle.

Move and draw

forward(distance)

fd(distance)

param distance : a number

Move the turtle forward by the specified distance, in the direction the turtle is headed.

back(distance)

bk(distance) backward(distance)

param distance : a number

Move the turtle backward by distance, opposite to the direction the turtle is headed. The turtle's heading does not change.

right(angle)

rt(angle)

param angle : a number

Turn the turtle right by the specified angle. The angle is measured in degrees by default; the unit can be changed with [degrees] or [radians]. How the heading is measured depends on the turtle mode, see [mode].

left(angle)

lt(angle)

param angle : a number

Turn the turtle left by the specified angle. The angle is measured in degrees by default; the unit can be changed with [degrees] or [radians]. How the heading is measured depends on the turtle mode, see [mode].

goto(x, y=None)

setpos(x, y=None) setposition(x, y=None)

param x : a number or a pair/vector of numbers

param y : a number or None

Move the turtle to an absolute position. If y is None, x must be a pair of coordinates or a [Vec2D], for example as returned by [pos]. If the pen is down, a line is drawn. The turtle's heading does not change.

teleport(x=None, y=None, *, fill_gap=False)

param x : a number or None

param y : a number or None

param fill_gap : a boolean

Teleport, or instantly move, the turtle to an absolute position. Unlike [goto], no line is drawn. If x or y is not given, that coordinate is kept as it is. The turtle's heading does not change.

If the turtle is filling a shape, the shape drawn so far is finished and filled before teleporting, and filling starts again at the new position. Pass fill_gap=True to keep filling one shape instead. The teleport then counts as an edge of the shape, as it would with [goto].

setx(x)

param x : a number

Set the turtle's x coordinate to x. The y coordinate is unchanged.

sety(y)

param y : a number

Set the turtle's y coordinate to y. The x coordinate is unchanged.

setheading(to_angle)

seth(to_angle)

param to_angle : a number

Set the turtle's heading to to_angle. Here are some common directions in degrees:

standard mode logo mode

0 - east 0 - north 90 - north 90 - east 180 - west 180 - south 270 - south 270 - west

home()

Move the turtle to the origin, coordinates (0,0). The turtle's heading is set to its start orientation, which depends on the turtle mode, see [mode].

circle(radius, extent=None, steps=None)

param radius : a number

param extent : a number or None

param steps : an integer or None

Draw a circle with the given radius. The center is radius units left of the turtle; extent, an angle, determines which part of the circle is drawn. If extent is not given, draw the entire circle. If extent is not a full circle, one endpoint of the arc is the current pen position. Draw the arc in counterclockwise direction if radius is positive, otherwise in clockwise direction. Finally, the turtle's heading is changed by extent.

As the circle is approximated by an inscribed regular polygon, steps determines the number of steps to use. If not given, it will be calculated automatically. May be used to draw regular polygons.

dot()

dot(size) dot(color, /) dot(size, color, /) dot(size, r, g, b, /)

param size : a positive integer or None

param color : a colorstring or a numeric color tuple

Draw a circular dot with diameter size, using color. If size is not given, the larger of pensize + 4 and 2 * pensize is used. If color is not given, the current pencolor is used.

stamp()

Stamp a copy of the turtle shape onto the canvas and return its id. The stamp is placed at the current turtle position. The returned id can be used to delete the stamp with [clearstamp].

clearstamp(stampid)

param stampid : an integer

Delete the stamp with the given stampid. stampid must be the return value of a previous [stamp] call.

clearstamps(n=None)

param n : an integer or None

Delete all or the first or last n of the turtle's stamps. If n is not given, delete all stamps. If n is positive, delete the first n stamps. If n is negative, delete the last n stamps, so -2 deletes the last two.

undo()

Undo (repeatedly) the last turtle action(s). Number of available undo actions is determined by the size of the undobuffer.

speed(speed=None)

param speed : an integer, a string or None

Return or set the turtle's speed. If speed is not given, return the current speed. Otherwise set the turtle's speed to an integer from 0 to 10. If speed is a number greater than 10 or smaller than 0.5, the speed is set to 0. You can also use these names instead of numbers:

  • "fastest": 0
  • "fast": 10
  • "normal": 6
  • "slow": 3
  • "slowest": 1

Speeds from 1 to 10 give increasingly faster animation of line drawing and turtle turning. A speed of 0 means that no animation takes place: [forward] and [back] make the turtle jump, and likewise [left] and [right] make the turtle turn instantly.

Pen control

Drawing state

pendown()

pd() down()

Lower the pen. The turtle draws a line when it moves.

penup()

pu() up()

Lift the pen. The turtle does not draw when it moves.

pensize(width=None)

width(width=None)

param width : a positive number or None

Return or set the line thickness. If width is not given, return the current pensize. If resizemode is set to "auto" and the turtle shape is a polygon, that polygon is drawn with the same line thickness.

pen(pen=None, **pendict)

param pen : a dictionary or None

param pendict : keyword arguments with the keys below

Return or set the pen's attributes. The attributes are returned as a dictionary with the following keys and values:

  • "shown": True or False
  • "pendown": True or False
  • "pencolor": a color string or a color tuple
  • "fillcolor": a color string or a color tuple
  • "pensize": a positive number
  • "speed": a number from 0 to 10
  • "resizemode": "auto", "user" or "noresize"
  • "stretchfactor": a pair of positive numbers
  • "shearfactor": a number
  • "outline": a positive number
  • "tilt": a number

Such a dictionary can be passed as pen to restore a former pen state. The attributes can also be given as keyword arguments, which can be used to set several of them in one statement.

isdown()

Return True if the pen is down, False if it's up.

Color control

pencolor()

pencolor(color, /) pencolor(r, g, b, /)

Return or set the pencolor.

Four input formats are allowed:

pencolor()

: Return the current pencolor as color specification string or as a tuple (see example). May be used as input to another [color], [pencolor], [fillcolor] or [bgcolor] call.

pencolor(colorstring)

: Set the pencolor to colorstring, which is a Tk color specification string, such as "red", "yellow", or "#33cc8c".

pencolor((r, g, b))

: Set the pencolor to the RGB color represented by the tuple of r, g, and b. Each of r, g, and b must be between 0 and colormode, where colormode is either 1.0 or 255 (see [colormode]).

pencolor(r, g, b)

: Set the pencolor to the RGB color represented by r, g, and b. Each of r, g, and b must be between 0 and colormode.

If the turtle shape is a polygon, the outline of that polygon is drawn with the newly set pencolor.

fillcolor()

fillcolor(color, /) fillcolor(r, g, b, /)

Return or set the fillcolor.

Four input formats are allowed:

fillcolor()

: Return the current fillcolor as color specification string, possibly in tuple format (see example). May be used as input to another [color], [pencolor], [fillcolor] or [bgcolor] call.

fillcolor(colorstring)

: Set the fillcolor to colorstring, which is a Tk color specification string, such as "red", "yellow", or "#33cc8c".

fillcolor((r, g, b))

: Set the fillcolor to the RGB color represented by the tuple of r, g, and b. Each of r, g, and b must be between 0 and colormode, where colormode is either 1.0 or 255 (see [colormode]).

fillcolor(r, g, b)

: Set the fillcolor to the RGB color represented by r, g, and b. Each of r, g, and b must be between 0 and colormode.

If the turtle shape is a polygon, the interior of that polygon is drawn with the newly set fillcolor.

color()

color(color, /) color(r, g, b, /) color(pencolor, fillcolor, /)

Return or set the pencolor and fillcolor.

Several input formats are allowed. They use 0 to 3 arguments as follows:

color()

: Return the current pencolor and the current fillcolor as a pair of color specification strings or tuples as returned by [pencolor] and [fillcolor].

color(colorstring), color((r,g,b)), color(r,g,b)

: Inputs as in [pencolor]. Set both the pencolor and the fillcolor to the given value.

color(colorstring1, colorstring2), color((r1,g1,b1), (r2,g2,b2))

: Equivalent to pencolor(colorstring1) and fillcolor(colorstring2) and analogously if the other input format is used.

If the turtle shape is a polygon, the outline and interior of that polygon are drawn with the newly set colors.

See also: Screen method [colormode].

Filling

filling()

Return True if the turtle is filling, False otherwise.

fill()

Fill the shape drawn in the [with] block.

[fill] is a context manager, so using it is the same as calling [begin_fill] before the block and [end_fill] after it:

begin_fill()

Call just before drawing a shape to be filled. The shape is filled by the next call to [end_fill].

end_fill()

Fill the shape drawn after the last call to [begin_fill].

If the shape crosses itself or several shapes overlap, whether the overlapping parts are filled depends on the operating system, the type of overlap and how many there are. For example, the turtle star above may be either all yellow or have some white regions.

More drawing control

reset()

Delete the turtle's drawings and re-center the turtle. The turtle's settings are restored to their default values.

clear()

Delete the turtle's drawings from the screen. The state and position of the turtle as well as the drawings of other turtles are not affected.

write(arg, move=False, align="left", font=("Arial", 8, "normal"))

param arg : an object

param move : a boolean

param align : a string

param font : a tuple of a string, an integer and a string

Write text at the current turtle position. The text is the string representation of arg. align is one of the strings "left", "center" or "right" and says how the text is placed relative to the turtle position. font is a triple of font name, font size and font type. If move is True, the pen is moved to the bottom-right corner of the text.

Appearance

shape(name=None)

param name : a string or None

Set the turtle shape to the named shape. If name is not given, return the name of the current shape. The shape must exist in the [TurtleScreen]'s shape dictionary. Initially there are the following shapes: "arrow", "turtle", "circle", "square", "triangle" and "classic". To add shapes, see the [Screen] method [register_shape].

resizemode(rmode=None)

param rmode : a string or None

Set the resizemode to "auto", "user" or "noresize". If rmode is not given, return the current resizemode. The different resizemodes have the following effects:

  • "auto": the turtle is resized according to the value of [pensize].
  • "user": the turtle is resized according to the stretch factors and outline width, which are set by [shapesize].
  • "noresize": the turtle is not resized.

resizemode("user") is called by [shapesize] when used with arguments.

shapesize(stretch_wid=None, stretch_len=None, outline=None)

turtlesize(stretch_wid=None, stretch_len=None, outline=None)

param stretch_wid : a positive number or None

param stretch_len : a positive number or None

param outline : a positive number or None

Return or set the turtle's stretch factors and outline width. If no arguments are given, return the current values. Otherwise set resizemode to "user", so that the turtle is displayed stretched according to its stretch factors:

  • stretch_wid: the stretch factor perpendicular to the turtle's heading
  • stretch_len: the stretch factor in the direction of the turtle's heading
  • outline: the width of the shape's outline

For example, shapesize(2, 1) makes the turtle twice as wide without changing its length. If only stretch_wid is given, stretch_len is set to the same value.

shearfactor(shear=None)

param shear : a number or None

Return or set the current shear factor. Shearing slants the turtle shape, like the slant of italic letters. The shear factor says how much it is slanted: 0 is not slanted at all, and the larger the number, the stronger the slant. Negative numbers slant the other way. If shear is not given, return the current shear factor. Otherwise slant the turtle shape accordingly and set resizemode to "user". The turtle's heading does not change. Precisely, the shear factor is the tangent of the shear angle.

tilt(angle)

param angle : a number

Turn the turtle shape by angle from its current tilt angle. The turtle's heading does not change, so the turtle keeps moving in the same direction. See [tiltangle].

tiltangle(angle=None)

param angle : a number or None

Return or set the current tilt angle. The tilt angle is the angle between the direction the turtle shape points in and the direction the turtle moves in. Normally the shape points in the direction of movement, so the tilt angle is 0. If angle is given, turn the turtle shape to that tilt angle, no matter what it was before, and set resizemode to "user". The turtle's heading does not change. If angle is not given, return the current tilt angle.

shapetransform(t11=None, t12=None, t21=None, t22=None)

param t11 : a number or None

param t12 : a number or None

param t21 : a number or None

param t22 : a number or None

Return or set the transformation matrix of the turtle shape. The matrix combines the stretch factors, the shear factor and the tilt angle of the turtle shape into four numbers: t11 and t12 form its first row, t21 and t22 its second. If none of them are given, return the current matrix as a tuple of four numbers. Otherwise set the given elements and update the stretch factors, shear factor and tilt angle accordingly. t11 * t22 - t12 * t21 must not be zero, otherwise an error is raised.

get_shapepoly()

Return the points that form the outline of the current turtle shape as a tuple of (x, y) coordinate pairs. These points can be used to define a new shape or parts of a compound shape

Animation control

no_animation()

Temporarily turn off turtle animation. The code inside the [with] block is not animated. Once the block is exited, the drawing appears. This is useful for drawing complex shapes where even the fastest speed setting is too slow.

delay(delay=None)

param delay : a nonnegative integer or None

Return or set the drawing delay in milliseconds. This is approximately the time interval between two consecutive canvas updates. The longer the drawing delay, the slower the animation.

tracer(n=None, delay=None)

param n : a nonnegative integer or None

param delay : a nonnegative integer or None

Turn turtle animation on or off and set the drawing delay. If n is given, only every n-th regular screen update is performed, which can be used to speed up the drawing of complex graphics. If n is 0, animation is turned off and the screen is only updated by calling [update]. If delay is given, it sets the drawing delay, see [delay]. When called without arguments, return the current value of n.

update()

Perform a TurtleScreen update. To be used when tracer is turned off.

See also the RawTurtle/Turtle method [speed].

param mode : a string or None

Set the turtle mode and perform a reset. mode is one of the strings "standard", "logo" or "world". If mode is not given, return the current mode.

Mode "standard" is compatible with the old [!turtle] module. Mode "logo" is compatible with most Logo turtle graphics. Mode "world" uses user-defined world coordinates, see [setworldcoordinates]. In this mode, angles appear distorted if the x and y units are not of equal length.

Mode Initial turtle heading positive angles

"standard" to the right (east) counterclockwise "logo" upward (north) clockwise

Return the colormode or set it to 1.0 or 255. After setting it, the r, g and b values of color triples have to be between 0 and cmode.

How to use the turtle module namespace

Using from turtle import * is convenient - but be warned that it imports a rather large collection of objects, and if you're doing anything but turtle graphics you run the risk of a name conflict (this becomes even more an issue if you're using turtle graphics in a script where other modules might be imported).

The solution is to use import turtle - fd() becomes turtle.fd(), width() becomes turtle.width() and so on. (If typing "turtle" over and over again becomes tedious, use for example import turtle as t instead.)
